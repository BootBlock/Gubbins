# Bulk edit & clone

Editing items one at a time is fine for a handful — but when you need to re-category fifty items
or duplicate a template, Gubbins has **bulk edit** and **clone** to do it in one go.

**Where to find it:** the **select mode** on the Inventory screen (via the **More** menu), then
choose items and apply an action.

## Selecting items

Turn on selection mode from the Inventory **More** menu, then tick the items you want. A toolbar
shows what you can do to the whole selection at once.

## Bulk edit

Apply a change to **every selected item** in one action — for example:

- Move them all to a [[location|Locations-and-Stock]].
- Set or change their **category**.
- Add or remove a **[[tag|Tags-Attachments-and-Related-Items]]**.
- [[Check them all out|Loans-Check-Out-and-In]] to a contact, or move them all in one step.

> **💡 Tip**
> Bulk actions are the fast way to tidy up after an import or a reorganise — import a rough list,
> then select-all and set the category and location in two clicks.

## Clone

**Clone** duplicates an existing item as the starting point for a new one — ideal when you add
lots of similar items. Set up one item exactly how you like it (fields, category, custom fields)
and clone it rather than starting from scratch each time.

> **ℹ️ Note**
> Cloning copies an item's *definition*, not its stock history — the new item starts fresh, so
> its [[activity log|Activity-Log]] and counts are its own.

> **⚠️ Heads-up**
> Bulk changes apply to **every** selected item at once and can affect a lot of records. Check
> the selection count before you apply — and remember most changes are visible in each item's
> [[activity log|Activity-Log]] if you need to see what happened.
