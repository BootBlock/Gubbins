# Condition grading

Beyond *how many* and *where*, you often want to know **what state** something is in. Gubbins
gives every item a structured **condition** grade — useful for collections, second-hand stock,
and anything that goes out on loan.

**Where to find it:** an item's **condition** is set on its details.

## The grades

Condition is a fixed set of grades, so it stays consistent and searchable across your whole
inventory:

| Grade | Meaning |
| --- | --- |
| **Mint** | As-new, unused or pristine. |
| **Good** | Used but sound and fully serviceable. |
| **Needs Repair** | Faulty or damaged — not ready for use. |
| **Out for Calibration** | Away being calibrated or serviced, so temporarily unavailable. |

An item can also have **no** condition set, if grading doesn't apply to it.

> **💡 Tip**
> *Out for Calibration* pairs naturally with [[test & calibration
> records|Test-and-Calibration-Records]] — set it while a unit is away, then grade it back to
> *Good* (or *Mint*) and log the calibration result when it returns.

> **ℹ️ Note**
> Because condition is a fixed grade rather than free text, you can filter and report on it
> reliably — *"everything that Needs Repair"* is a dependable [[search|Search-Overview]], not a
> guess at how it was typed.
