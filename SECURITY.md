# Security policy

Gubbins is a local-first application: your inventory data lives in your own browser — or on
your own machine when you run the optional bridge — and there is no Gubbins-operated server
holding your data. Even so, security reports are very welcome.

## Reporting a vulnerability

**Please report security vulnerabilities privately — do not open a public issue.**

Use GitHub's private vulnerability reporting:

1. Open the [Security tab](https://github.com/BootBlock/Gubbins/security) of this repository.
2. Click **Report a vulnerability**.
3. Describe the issue, its impact, and the steps to reproduce it.

You will get a response as soon as reasonably possible. Please allow a reasonable amount of
time for the issue to be addressed before disclosing it publicly.

## What to include

- The affected area — the web app, the optional bridge / integrations, or a dependency.
- The version or commit, and the browser/OS or runtime where you observed it.
- A minimal proof of concept, if you have one.

## Supported versions

This is an actively developed, pre-1.0 project. Only the latest `main` — and the most recent
deployed build — is supported. Fixes land on `main`; please retest there before reporting.
